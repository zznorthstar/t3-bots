# Changelog

## 0.1.10-preview.bots.4 — First public source preview

T3 Code with an experimental Bot HQ integration, published separately because we do not think a bot team belongs in core T3 for most users.

### Included

- Bot creation and navigation in the T3 sidebar, bot conversations, and a Bot panel alongside existing panels.
- Local Hermes desktops, live viewing, human takeover and return of control.
- Team discussions and group conversations with correct sender identities.
- Local voice calls with interruption and a separate prompt-dictation control.
- Attachments, uploaded avatars, a global display name and per-bot SOUL.md editing.
- Linking of existing default and named Hermes profiles, including Discord and Telegram context.
- Linux desktop packaging, a per-user installer and a separate data directory.
- A pinned Bot HQ runtime, public setup documentation, attribution and repository checks.

### Release limits

This public preview is distributed as source. Desktop packaging has been exercised locally on Ubuntu 26.04 x64. Portable binaries, macOS/Windows bot support, mobile bot screens and automatic upstream merge-and-release updates are not part of this release. Profile splitting and Telegram-history migration require deliberate manual setup and backups.
